# ClipForge

## Register

product

## Users
Windows gamers who want to preserve a moment with F8, without leaving their game or creating an account.

## Product Purpose
Keep a local replay buffer, save playable clips, find them in a library, trim and export them offline.

## Brand Personality
Quiet, precise, dependable. French interface, concise labels, real capture state always visible.

## Anti-references
No web dashboard, social feed, advertising, invented statistics, default Qt widget appearance or reproduction of Medal artwork.

## Design Principles
Capture reliability first. One clear save action. Original videos remain accessible. Explain fallbacks. Disable unsupported operations explicitly.

## Accessibility & Inclusion
Keyboard focus, readable contrast, Windows DPI scaling, state labels alongside colors, restrained motion.
