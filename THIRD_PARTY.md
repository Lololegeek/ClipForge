# Inventaire des composants tiers distribués

Le code source de ClipForge est sous licence GPL-3.0 ou ultérieure. libobs est sous GPL-2.0 ou ultérieure, compatible avec la GPLv3. Qt est lié dynamiquement selon ses conditions open source. Aucun code ni aucune illustration de Medal n'est utilisé.

* Exécutable OBS Studio 32.2.2 et sources correspondantes : https://github.com/obsproject/obs-studio/releases/tag/32.2.2 . L'archive des sources est conservée dans `.deps/obs-source.tar.gz` ; la licence d'OBS est copiée dans le dossier portable. L'exécutable contient d'autres dépendances (FFmpeg, x264, GPU, etc.).
* Binaires open source Qt 6.8.3 MSVC2022 issus de l'archive en ligne de Qt via aqtinstall 3.3.0. Sources correspondantes : https://download.qt.io/archive/qt/6.8/6.8.3/single/ . Modules Qt utilisés : Core, Gui, Widgets, Qml, Quick, QuickControls2, Multimedia, Sql, Svg, ShaderTools et leurs dépendances d'exécution. SQLite est utilisé via le pilote de Qt.
* FFmpeg 7.1.1, version minimale personnalisée (GPLv3, bibliothèques partagées) compilée à partir des sources officielles non modifiées https://ffmpeg.org/releases/ffmpeg-7.1.1.tar.xz avec MSYS2 MinGW-w64 ; elle utilise x264 (GPLv2+), x265 (GPLv2+), libwebp (BSD-3-Clause) et zlib. La configuration exacte se trouve dans `packaging/ffmpeg-mini/` (recette) et dans `licenses/FFmpeg-build.txt` (sortie de `ffmpeg -version`). Les DLL d'exécution MinGW-w64 (libgcc, libstdc++, winpthread) sont redistribuées selon leur exception d'exécution ou leurs licences permissives. L'exécutable OBS fournit ses propres bibliothèques FFmpeg, distinctes.
* L'exécution MSVC est déployée par windeployqt, selon les conditions de redistribution de Microsoft.

Les sources publiées avec chaque version comprennent l'archive des sources d'OBS 32.2.2, l'archive complète des sources de Qt 6.8.3, l'archive des sources de FFmpeg 7.1.1, la recette de la version minimale de FFmpeg (`packaging/ffmpeg-mini`) et les recettes de compilation des dépendances d'OBS (2026-07-15, selon les préréglages CMake d'OBS). Les textes des licences de Qt et les inventaires SPDX des modules fournis, la licence d'OBS et les textes et la configuration des licences de FFmpeg (dont les conditions GPL de x264/x265) sont dans `licenses/`, dans l'application installée comme dans la version portable. SHA256SUMS.txt identifie les fichiers de la version.

Ces archives documentent les composants directs ; un audit complet de toutes les bibliothèques indirectes de la distribution OBS précompilée n'a pas été réalisé. Aucune conformité complète des composants tiers n'est affirmée.
